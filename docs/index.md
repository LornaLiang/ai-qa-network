# ai-qa-network

当代人工智能的问答笔记库：用简短条目解释概念与方法，并通过“相关问题”互相链接形成知识网络。

**怎么用：**
- 左侧按分类浏览（建议从“数学基础 → 深度学习 → Transformer → LLM”开始）
- 每篇末尾有“相关问题”，用于继续深入或回到前置概念
